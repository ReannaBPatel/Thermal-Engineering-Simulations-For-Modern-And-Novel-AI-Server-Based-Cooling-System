# Thermal-Engineering-Simulations-For-Comparing-Modern-And-Novel-AI-Server-Based-Cooling-Systems
These simulations employ the Thermal Engineering Systems in Python (TesPy) framework to model both standard (direct-to-chip) and proposed novel server cooling systems for hyperscale AI data centers. Results from both models help quantify energy-efficiency and evaluate simulated advantages of the novel system.

This repository includes two models, one simulating a direct-to-chip system and one simulating a proprietary novel system. Each model contains a distinct thermal network, yet they produce the same graphs to serve as comparisons between each system.
